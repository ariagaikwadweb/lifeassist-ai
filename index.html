About LifeAssist AI

LifeAssist AI was built to help families understand their financial habits in a simple and friendly manner. Most people do not track where their money goes, which leads to confusion, stress, and unplanned expenses.

🎯 Our Mission

  • Make budget tracking simple for EVERY user
  • Provide AI-style recommendations without internet requirement
  • Support low-income and offline households
  • Help students learn full-stack development + analytics

💼 Technologies Used

Flask Backend SQLite DB JavaScript Chart.js Responsive UI AI Planner Logic

📘 Educational Value

This project demonstrates core skills needed in modern development:

  • Authentication & secure session handling
  • REST APIs and CRUD operations
  • Data visualization and analytics
  • AI-style budgeting logic & financial insights
  • Offline-friendly data management
